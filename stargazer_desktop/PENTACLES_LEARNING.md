# Pentacles 学习记录

共性个性模型（星币侍从）每日复盘档案。**每日收盘后追加一篇，不改旧篇。**
用途：积累 Pentacles 观察名单的前瞻证据，检验"共性资格→关注区域→触区→承接→结局"链条的各环节质量。

## 数据契约（每篇固定字段）

| 字段 | 说明 |
|---|---|
| 数据日 / 观察日 | 名单快照的日线日期 / 被观察的交易日 |
| 名单来源 | snapshot.json（data_date、候选数、setup 分布） |
| 市场背景 | 当日大盘方向（弱市/强市/震荡，一句话）——个股结局必须对照 beta 解读 |
| 总体数字 | 触区率、触区组收盘均值/中位/收阳数 |
| 典型案例 | 真反弹 / 反弹吐回 / 触区续跌 各 1-3 只（代码+数字） |
| 当日判读 | 只陈述事实与比例，不因单日结果改任何阈值/规则 |
| 累计索引 | 各日触区组收盘均值序列（滚动对照） |

**纪律**：单日复盘不构成统计结论；触区≠买点（需承接确认）是所有结局的默认解释框架；本记录不是新盲测（观察规则在持续查看中），正式前瞻窗口以影子协议（#16.26/16.27）批准后的 T0 起算。
