# DeepSeek 次日计划与星币侍从复盘（2026-10-14）

唯一活动桌面入口：`D:\stargazer\stargazer_desktop\dist\Stargazer.exe`。

## 使用

1. 先更新 stockdb，点击星币侍从「盘后总结 · 分析选股」。
2. 「制定次日计划」直接进入原 AI 对话。可继续聊天修改候选；「确认计划并开启次日提醒」才冻结名单。新名单不得把旧确认计划静默替换。报价提醒非买入信号，软件需保持运行，微信需开启顶部推送。
   当前自动监控范围是候选名单及原冻结区域到价；聊天里的复杂承接/失效条件由人复核，不自动翻译为执行DSL。
3. 「写入学习记录」在星币侍从页内选择观察日、生成预览。后台只读本机日K和归档名单，DeepSeek整理解释；你确认后才追加，重复确认不重复写。
4. 「普通对话」退出计划讨论模式。普通对话同样使用DeepSeek，保留原有明确人工操作命令。
5. 设置中可重新填写DeepSeek密钥，不回显。凭据是当前 Windows 用户 DPAPI 文件 `.secrets/deepseek.dpapi`；不进exe、不进Git。迁移到另一台电脑/用户须重新填写。聊天中暴露过的密钥建议轮换。

## 记录位置与边界

- 草案/对话/确认记录：exe旁 `data/assistant/`；确认名单：`data/pentacles_demo/assistant_plan.json`。报价、旧名单和研究模型不混写。
- 本开发机学习记录继续写 `stargazer_desktop/PENTACLES_LEARNING.md`；若迁移到独立目录，写exe旁同名文档。每次界面显示实际保存路径。
- 行情事实与 AI 解释分开。市场来源未知就保留未知；日线触区不证明真实触发时刻，名单参考价与日K口径未核销时只是描述。
- stockdb HTTP不可用时只读已同步分片的同一观察日日线，并展示来源；不使用昨日价格代替今日。两源都缺数据就拒绝调用DeepSeek生成复盘。
- 七日入场日计第1日，第7交易日固定收盘参考；MFE/MAE只描述路径，不以最高/最低点选择退出。买入日前/当日入场前的高低不进入可卖表现。
- 当前报价提醒不产生认证成交。旧 tracker 无尺度/成交/公司行为/退出验收时，七日可执行净收益为NULL。合成验收通过不替代真实成交证据。
- 真实交易独立读取原成交库。股数/完整匹配缺失保持未知；仅已匹配成交可报毛盈亏，费用未记录则净盈亏NULL，不归因到模型。
- 助手目录10MiB护栏、学习文档2MiB护栏；DeepSeek每日最多40请求及120000Token保守预约预算，失败也消耗预约，不静默重试。研究128MiB累计规则不因桌面更新重置。
