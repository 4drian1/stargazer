**REV2-A 缓存核验**（v02_cache_coverage_probe.json）已确认：

## 1. 事件起点（Event Origin）

- **起点 = `signal_ts`**（`detect_signal` 返回的触发时刻，监控窗 [09:35,14:55] 内目标区域首个触发 bar 的时间戳），**不是** `fill_ts`（成交时刻）。
- 理由：基础行为画像研究的是"价格触及/跌破锚点后的反应"，起点是锚点被触及的那一刻；`fill_ts` 含执行摩擦（下一可执行分钟），属条件交易价值层，不混入行为画像。
- 非池资格日事件（setup=None）**保留**，作为该股历史行为画像的一部分，但**不**当 A/B 买点期望、不重标 A/B。

### 1.1 行为画像事件入选门槛（REV2 收紧：不依赖成交）

**行为有效性 ≠ 执行有效性**。行为画像的事件入选只要求"行情窗口完整"，**不要求成交**：

| 状态 | 行为画像（穿透/收回） | 收益标签（y/f） |
|---|---|---|
| FILLED | 入选 | 入选 |
| NO_FILL_ZERO_QTY（行情完整但零可成交） | **入选**（行情窗口完整即可观察穿透/收回） | 不入选（无成交） |
| NO_FILL_UNLABELED（无合法可执行分钟） | 看行情是否完整，完整则入选 | 不入选 |
| HALTED_UP_APPROX | 不入选（涨停近似，行情异常） | 不入选 |
| SOURCE_MISSING / INVALID_DAY | 不入选（行情不完整） | 不入选 |
| ADJ_UNKNOWN | 不入选（复权失败，穿透/收回跨日失真） | 不入选 |
| EXIT_DEFERRED_FAILED / EXIT_UNAVAILABLE | 行为画像窗口（≤10d）仍入选；收益标签不入选 | 不入选 |

- **收益标签**才需要成交（y/f 只对 FILLED 计算），行为画像不需要。
- NO_FILL_ZERO_QTY 事件若行情窗口完整，其穿透/收回仍有效——不能因没成交就丢弃行为观察。

## 2. 固定观察窗（Fixed Observation Window）— REV2 预注册主检验

### 2.1 预注册主检验窗口（REV2 收紧：禁止看完结果再选窗口）

**REV1 允许按 CI 挑 30m/60m/5d/10d 中通过的一档，会产生择优报告。REV2 预注册如下，检验时不许更换：**

| 窗 | 长度 | 角色 | 备注 |
|---|---|---|---|
| W_60m | 信号后 60 交易分钟 | **盘中画像主检验**（预注册） | 分钟级，行为画像稳定性以此为主 |
| W_30m | 信号后 30 交易分钟 | 辅助检验 | 分钟级，仅作辅助参考，不单独判稳定性 |
| W_5d | 信号后 5 个交易所日 | 辅助检验 | 日线+日内混合 |
| W_10d | 信号后 10 个交易所日 | 辅助检验 | 同上 |

- **稳定性主检验 = W_60m**。辅助窗（30m/5d/10d）报结果但**不单独判稳定性成立**；若主窗未达 §7.2 而某辅助窗达标，**不**据此宣布稳定（避免择优）。
- **交易价值主口径**仍按原 H3（持有期 3 交易所日，`EXIT_HOLD_DAYS=3`），不在本协议改。H3 收益标签的稳定性属"交易增量"层（§7.3），与行为画像稳定性（§7.2，W_60m 主）分开。

### 2.2 窗口数据质量（各窗独立，REV2 钉死）

- 分钟窗（W_30m/W_60m）覆盖缺失槽 → **该事件该窗特征置 INVALID**，不插值不补零（沿用 `reclaim30_invalid` 口径，扩展到 60m）。
- **各窗口分别记录完整性与截断状态**：W_30m 不完整**不否定**已完整的 W_60m；W_60m 不完整**不否定**已完整的 W_5d。每个窗独立判定，不互相覆盖。
- 统一固定长度：所有事件用同一档窗比较，不按事件结果动态截断。

## 3. 收回定义（Reclaim Definition）— REV2 钉死

**当前引擎未实现真收回率**（仅 `reclaim30_invalid` 数据质量标记 + `f` 3 日跌破标签）。REV2 钉死如下，待引擎补字段后计算：

### 3.1 起点与终点

- **起点** = 已完成的信号 bar（`signal_ts` 对应的 bar）。固定窗口的终点使用**交易所日历（`cal`）和交易分钟槽位**，不用自然时间。
- 分钟窗终点 = 信号后第 N 个**交易分钟槽位**（按 `expected_grid` 感知 13:00 源格式）。
- 日线窗终点 = 信号后第 N 个**交易所交易日**（`cal` 索引）。

### 3.2 收回的严格定义（区分"已在上方"vs"跌破后收回"）

**收回（reclaim）仅计"先跌破 zone_lower 后回到 zone_upper 及以上"的事件**。关键区分：

- **本来就在区域上方**（信号是 APPROACH，或 ALREADY_BELOW 后价格直接反弹回 zone_upper 而从未在 zone_lower 下方）→ **不算收回成功**。记录 `reclaim_status = "ALREADY_ABOVE"`，不计入收回率分子。
- **跌破后收回**（价格曾 ≤ zone_lower，之后回到 ≥ zone_upper）→ `reclaim_status = "RECLAIMED"`，计入收回率分子。
- **未收回**（窗口内价格曾 ≤ zone_lower 但始终未回到 ≥ zone_upper）→ `reclaim_status = "NOT_RECLAIMED"`。

### 3.3 收回使用 close 还是 high（不混用，同 bar 显式标记）

- **主口径：收回用已完成 bar 的 close**（不用 high）。理由：close 是 bar 收盘已确认价，high 是日内极值，混用会让"触及 zone_upper"与"收在 zone_upper"不可比。
- **同 bar 先后顺序无法确定时显式标记**：若信号 bar 本身 close ≥ zone_upper 但 low ≤ zone_lower（同 bar 内先跌破后收回），因 1 分钟内先后顺序无法确定，`reclaim_same_bar_ambiguous = True`，单独计 `n_ambiguous`，不强行归入 RECLAIMED 或 NOT_RECLAIMED。
- 逐 bar 扫描时，用每个 bar 的 close 判定是否 ≥ zone_upper；穿透用 low 判定是否 ≤ zone_lower。

### 3.4 各窗收回字段

- `reclaim_30m` / `reclaim_60m` / `reclaim_5d` / `reclaim_10d`：窗内收回状态（`RECLAIMED` / `NOT_RECLAIMED` / `ALREADY_ABOVE` / `AMBIGUOUS`）。
- `time_to_first_reclaim`：从 `signal_ts` 到首次收回的交易分钟/交易所日数。

### 3.5 未收回时间不用"窗长+1"参与平均（REV2 收紧）

- **未收回事件的 `time_to_first_reclaim` 留 NULL**，不填"窗长+1"哨兵值。
- 单独记录：`n_reclaimed` / `n_not_reclaimed` / `n_already_above` / `n_ambiguous`。
- 平均/中位数只对 `reclaim_status == "RECLAIMED"` 的事件计算，并对缺失比例显式报告（如"收回时间中位 X 分钟，基于 n_reclaimed 个收回事件，占总体 Y%"）。
- 记录观察终点（窗口实际结束的 ts）与截断标志（窗口是否被数据缺失/未来扰动截断）。

### 3.6 收回 vs 失败分立

- `failure_3d`（=现 `f`）= 持有期 3 日内 `min_low < buy_net - 0.5*ATR_ref`（跌破成本-缓冲）。这是**成本侧**的失败标签，**不等于**"未收回锚点"。
- 二者分别统计，**不得互换名称**：未失败（没跌破成本）≠ 已收回锚点（可能还在 zone_lower 附近但高于成本）。

## 4. 穿透深度：同刻 vs 全窗（Penetration）

可行性报告已纠正：`pen_atr_bar` 仅信号 bar 穿透（中位 0.11 ATR），`pen_full_window` 持有期最大穿透（中位 1.01 ATR）——二者量级差 10 倍，是不同问题。本协议明确：

| 指标 | 定义 | 用途 | 是否事后标签 |
|---|---|---|---|
| `pen_signal_bar` | `(zone_lower - lo_signal_bar)/atr_ref` | 触发瞬间的穿透（"第一次触碰有多深"） | 否（当时可知） |
| `pen_at_time_t` | `(zone_lower - low_t)/atr_ref` 逐时刻 | 路径刻画（可选，诊断用） | 否 |
| `pen_full_window_max` | `(zone_lower - min_low_window)/atr_ref` | **主画像用**："后来通常杀到哪里" | **是（全窗最大穿透，事后才知）** |
| `time_to_max_pen` | 从 `signal_ts` 到达 `min_low_window` 的时刻 | 到达最深点的速度 | **是（事后才知）** |

### 4.1 事后标签不进当时决策（REV2 钉死）

- **`pen_full_window_max`、`time_to_max_pen`、全窗最大穿透属事后画像标签，不能进入当时决策**。这些字段只用于事后画像刻画与稳定性检验，不作为决策函数（mu/p 门槛）的输入。
- 决策函数只能用当时可知的 `pen_signal_bar`（信号 bar 穿透）。
- `min_low` 现已由引擎暴露（`label_event` 返回 `min_low`，fill_date 同尺度，与 `zone_lower` 可直接比较）。
- 全窗穿透按 W_30m/W_60m/W_5d/W_10d 分别算 `min_low_window`（取该窗内最低），不混用持有期窗。

### 4.2 穿透深度保持非负

- `(zone_lower - low)/atr_ref` 若 low > zone_lower（未跌破）则值 < 0，此时**保持非负**：`max(0.0, (zone_lower - low)/atr_ref)`。负值无意义（未穿透）。

## 5. 时间切分（Time Split）— REV2 早晚预测误差增量

### 5.1 稳定性证据 = 早晚预测误差增量（REV2 收紧）

**REV1 用"早/晚点估计同号且 CI 不跨 0"作稳定性证据，但穿透/收回本就非负，"同号""CI不跨0"不是稳定性证据。REV2 改为：**

- **稳定性证据 = 早段画像预测晚段事件，相比组统计是否降低误差**。
- 早段（build）：切分点之前的事件 → 估计个股画像 + 跨股共享画像。
- 晚段（test）：切分点之后的事件 → 用早段画像预测，记录预测误差。
- **判稳定性 = 个股画像预测晚段的 RMSE（连续指标）/ Brier（0-1 指标）显著低于组统计预测的 RMSE/Brier**，bootstrap CI 不跨 0 的增量。
- 不只看 early/late 相关（相关弱不代表无预测增量）。

### 5.2 切分前提：统一时间窗

当前 16 股缓存跨度严重不齐（4 股 <6 月，2 股 6-7 月边界，最长 19 月）。切分前：
1. 剔除/补齐短跨度股（见 §6 补抓登记）；
2. 切分点 = **统一日历中点**（所有入选股共同覆盖区间的中位数日期），不逐股取中位（逐股中位会让"早/晚"不可比）。

### 5.3 最短跨度门槛

- 每股早/晚各需 ≥10 事件（与 §7 CI 同门槛），否则该股该向剔除不计数（不弃条件但不计入稳定性判定）。

## 6. 定向历史扩展（补抓登记，不立即执行，范围待探测）

为满足 §5 统一时间窗，登记一次定向补抓（**不因结果不稳定再延长**）：

- **目标**：把短跨度股补到与长跨度股可比的统一窗口。
- **候选补抓股**：当前缓存跨度 < 12 个月的股。REV2-A 确认真实短股 = 300793/000042/301584/000078（4 只）+ 边界 603221/301357（2 只）。
- **补抓区间**：向更早历史延伸至 2024-01-02 起（与长股对齐到共同 ~20 个月窗），或至当前缓存起点。**范围标"待探测"**——原清单分钟研究范围从 2025-01-02 开始，补到 2024 须先探测真实覆盖，不能直接批准 2830 股日请求（缓存最早/最晚日期不代表中间连续覆盖，REV2-A 已验证多股有 240 槽异常日）。
- **标签延伸范围**：仅延伸**行为画像字段**（穿透/收回/失败，§3-§4），**不延伸 A/B 池资格**（非池事件保留当时背景，不重标）。
- **请求数/预算**：补抓分钟数据按缺股缺日计，预算上限**不在此冻结**，待第 3 步小量探测历史覆盖后再冻结。
- **停止规则**：补抓**一次**，不因结果仍不稳定再延长窗口。补抓后若仍不足 §7 停止条件 → 按"未成立"结案。

## 7. 置信区间与停止条件（CI & Stopping）

### 7.1 置信区间
- **个股画像**：每个指标（pen_full_window_max、time_to_first_reclaim、failure_3d、reclaim_*d）报 bootstrap 95% CI（B≥1000）或 t 区间（n≥10 时），不只看点估计。
- **跨股共享估计**：报收缩后的 mu_hat 与其 95% CI（收缩权重 λ ∈ [0,1]）。
- **预测误差增量**：早段画像预测晚段事件的 RMSE / Brier，报 bootstrap CI；增量 = 组统计误差 − 个股画像误差，报增量 CI。

### 7.2 稳定性成立条件（个性稳定）— W_60m 主检验

同时满足以下三项 → "个性稳定"成立（主检验 W_60m，辅助窗不单独判）：
1. **预测增量**（核心）：个股画像预测晚段的 RMSE（pen_full_window_max）/ Brier（reclaim_60m、failure_3d）**显著低于**组统计预测，bootstrap CI 不跨 0 的增量；
2. **早晚一致性**：个股画像指标早/晚点估计方向一致且 r ≥ 0.5（pen/reclaim/failure 三项至少两项）——作辅助证据，不单独判；
3. **样本充分**：每股早晚各 ≥10 事件且 CI 不跨 0（或跨 0 但方向与组一致且收缩后稳定）。

### 7.3 交易增量成立条件（个性有交易增量）

在 7.2 基础上，额外（仍按 H3 主口径）：
4. **成本后价值**：早晚 mu_hat（收益）均 > 0 且 CI 下界 > 0，p_fail ≤ 0.50 且 CI 上界 ≤ 0.50；
5. **超组统计**：个股或条件单元格估计的 mu 显著高于组统计 mu（CI 不跨 0）。

### 7.4 停止条件（不无限迭代）
- **达标**（7.2 全满足）：个性稳定成立 → 进 v0.2 主合同起草（决策函数）。
- **达标 + 7.3**：个性有交易增量 → 决策函数可纳入个股画像。
- **未达标但补抓已用尽**（§6 一次补抓后仍不满足 7.2）：画像仅保留**解释用途**，不进买入决策；v0.2 主合同回到"组统计 + 收缩"路径，不依赖个股个性。
- **禁止**：不因结果不稳定持续延长窗口或反复补抓；不看完辅助窗结果再选主窗口。

## 8. 不冻结项（显式）

本协议**不冻结**：
- 最终决策函数（mu/p 门槛、放行规则、λ 收缩权重取值）；
- A/B 共性选股口径（不动）；
- 单元格合并粒度（4 维 vs 较粗粒度的最终选择，待 §5 切分后据功效定）；
- W_30m/W_5d/W_10d 是否单独可用（已预注册 W_60m 为主，辅助窗不单独判稳定性）。
