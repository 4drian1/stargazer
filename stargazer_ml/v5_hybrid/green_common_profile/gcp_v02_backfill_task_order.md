## 2. 补抓目标（范围已冻结：2025-only）

- **统一窗口下限**：**2025-01-02**（canonical stockdb 分钟起点；2024 全缺，见 §2.1）。
- **补抓股候选**：4 短股（300793/000042/301584/000078）+ 3 边界股（603221/000016/301357）。
- **补抓方向**：向更早的 2025 区间延伸至 `20250102`，使每入选股早区间（切分点前）≥10 事件门槛（协议 §5）。
- **不延伸 A/B 池资格**：仅延伸行为画像字段（穿透/收回/失败，§3-§4），非池事件保留当时背景不重标。

### 2.1 为什么 2024 不可取（REV2-F 探测结论）

- canonical stockdb 分钟数据起点 = `20250102`（`discover_data_epoch` + REV2-F Phase1 探测确认）。
- Phase1 对 7 候选股 × 5 个 2024 日期（20240102/20240401/20240701/20241001/20241202）共 35 次采样：**0 OK / 24 SOURCE_MISSING / 4 SUSPENDED / 7 NOT_TRADING_DAY**。
  - SOURCE_MISSING = daily 有行且 volume>0，但分钟 HTTP 返回空 → 源真没有 2024 分钟。
  - SUSPENDED = 该股 daily 在该日无行（停牌/未上市）→ 本就无分钟可抓。
- 结论：**补抓不延伸到 2024**，缩小为 2025-only，回溯至 `20250102`（run_sheet `minute_window` 下界）。

### 2.2 2025 区间连续性（采样非穷举声明）

- Phase2 对 7 候选股各自 `[20250102, lookback_start)` 扩展区间，用 daily 行存在列出真实交易日（扣除停牌/非交易日），采样头中尾 6 个做分钟 HTTP 探针：**全部 6/6（000016 为 2/2）OK**。
- **采样非穷举**：6 点确认可取不代表区间内每个交易日 100% 有分钟；实补时按 `ext_days` 全列发请求，缺口随补随记（不用最早/最晚冒充连续覆盖，用户硬约束）。

### 2.3 20250508 源缺口（不可补，REV2-F Phase3 发现）

- 605398/603887 在 `20250508` 当日 daily volume 分别为 9,423,944 / 20,032,206（确有成交），但分钟 HTTP 返回空 → **SOURCE_MISSING**。
- 这不是原抓取的"漏抓"，是 canonical 源真缺该日该股分钟 → **重试无效**，标记为已知缺口，引擎按 `window_complete=false` 处理该窗，不重试。

### 2.5 异常槽位日=盘中缺口，涉及窗口必须 INVALID（REV2-F-correction PhaseB，纠正 v1 口径#1）
