- **规则 A = 现有 S1/S2 触发**（冻结语义：首触发归属，双触发 2 条逐条在案，见 v3）。

## §3 时间可见性铁律（冻结）

- 每套规则**只用决策当时可见信息**；决策时点之后的信息一律不得进入该规则判定。
- **"整天无行动"是收盘后才可确定的状态，不得当作早盘已知条件**；规则 B 与规则 A 均为早盘可判定规则。
- 确认不行动 → 留现金（记未行动，不记零收益）；数据不足 → NULL 单列不记零；残仓单列不折现金。
