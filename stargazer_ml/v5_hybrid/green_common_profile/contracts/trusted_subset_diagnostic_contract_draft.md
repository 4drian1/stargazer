## 1. 研究对象（冻结定义）

**现有可信子集** = 当前通过全部依赖检查的轨道（track）子集。H3/H5 **分别**扣除以下三类轨道：

1. **跨段隔离轨道**：`CROSS_SEGMENT_LABEL` 轨道（train 轨道 `label_end_ts ≥ 20260309`、val 轨道 `label_end_ts ≥ 20260610`；test 无下段）。逐轨道按 `label_end_ts` 所在交易日判定，判定规则与 v0.1.1 引擎一致，不得重判或放宽。
2. **公司行为证据未通过轨道**：窗口内复权/公司行为证据为 EMPTY、absent 或未落盘而未通过验收的轨道（沿用 244 OK + 3 EMPTY 验收口径，未通过者逐条登记）。
3. **尺度证据未通过轨道**：价格量纲、成交量纲或执行元数据证据未通过逐笔验证的轨道。

子集由冻结输入机械导出，**不得**根据子集外表现反向调整纳入规则。

## 2. 完整人口并列报告（冻结）

诊断必须**同时**报告：

- 完整 247 人口状态分布（SIM_COMPLETE / EXIT_DATA_MISSING / EXIT_DEFERRED_CAP / ENTRY_METADATA_UNKNOWN / CENSORED_TAIL / ISOLATED / CROSS_SEGMENT_LABEL 等，按段 × A/B 池 × 板块拆分，口径同 `gcp_247_phase1_status_p2b1.json`）；
- 每条排除记录的排除原因（逐轨道：排除类别①/②/③ + 原始 status/reason）；
- **不得以子集数字替代人口数字**；任何图表/摘要必须能回溯到人口分母。

## 3. 代表性声明（冻结）

收益/风险分布仅代表**可复放子集**（当前通过全部依赖检查且已闭环的轨道）。显式声明：

- 该分布**不是**全策略表现；
- 该分布**不用于**跨期有效性结论；
- 左尾若由数据缺口驱动，须与真实策略风险分离标注（缺口驱动左尾单独列示）；
- 完整率分段偏差（见第 6 条）使子集构成非随机，任何比较须带构成警示。

## 4. 禁止用途（冻结）

诊断结果禁止用于：

1. 调整任何阈值、参数或规则（止损带宽、顺延预算、容量、成本乘数等一律冻结）；
2. 选择"最佳退出"或退出方式偏好结论；
3. 启动或预热训练（含以诊断分布做样本加权/筛选）；
4. 按收益挑事件、挑时间段、挑板块构成子集。

违反以上任一项，诊断结果自动作废并登记审计。

## 5. 行为标签分离条款（冻结）

- 行为标签（缺口后 MAE/MFE/箱体等）**不是**本诊断的前置条件；
- 退出后行为标签缺失**不否定**已闭环交易（交易标签与行为标签分别判定，缺口后行为标签另判，二者解耦）；
- 本诊断只基于交易闭环依赖，不要求补齐行为窗口。

## 6. 测试段完整率偏差条款（冻结）

- 现有 test 段完整率显著低于 train（v0.1.2 实测：train 90.6% / val 61.8% / test 34.4%），test 子集样本量小且构成偏差未知；
- test 子集的任何结果必须附带**样本量与构成偏差警示**（n、完整率、排除构成）；
- **不得声明"新盲测"**：现有测试期事件已参与研究流程（选择、采集、工程核对），不构成独立前瞻验证；
- 跨期有效性结论只能来自**规则冻结后的新前瞻时段**，其数据采集与执行须另行批准。

## 7. 诊断输出范围（冻结）

仅限以下输出，超出即违规：

1. **逐笔收益分布**：H3/H5 成本后净收益（引擎 `net`，含滑点+费用，不二次加费）逐笔列示与分位数；
2. **风险分布**：分位数、最差例（worst case 逐笔列示）；**不做账户级最大回撤**——资金规模、并发持仓、仓位分配与估值规则未冻结，账户级指标在本合同范围外；
3. **排除原因统计**：三类扣除各自的轨道数与逐条原因汇总。

不输出：盈利排名、策略有效性裁决、买入建议、账户回撤、跨期外推。

## 9. 诊断指标定义（工程口径）

- **H3/H5 成本后净收益**：`net = C_sell / C_buy − 1`，`C_buy = shares × fill_price × 1.0013`，`C_sell = Σ sell_q × open × 0.9982`；引擎口径，直接采用不二次加费；仅 `fully_exited=True` 且依赖全过的轨道参与分布，残仓/NULL 不计零收益。
- **持有期**：`last_fill_ts − sim_fill_ts`（按交易日与分钟，分别报两个量纲）；STOP 触发的轨道单独标注触发日至成交日间隔。
- **退出方式构成**：TIME（计划 14:56 成交）/ STOP（止损触发后下一合法 bar 成交）/ 部分顺延卖出（deferral 内多笔 sells 的 kind 构成）；报告各退出方式的轨道数与占比。
- **风险分布**：净收益分位数（至少 P5/P25/P50/P75/P95）、最差 10 例逐笔列示；缺口驱动左尾单独标注。
- **排除原因统计**：第 1 条三类扣除 + 未闭环/NULL 的逐类计数。
- 全部指标按 H3/H5 分别报告，再按段（train/val/test）拆分；**禁止**跨段合并成单一数字。
