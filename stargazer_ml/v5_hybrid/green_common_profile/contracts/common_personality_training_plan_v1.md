# 共性＋个性继续训练计划 v1

状态：DRAFT_REQUIRES_USER_APPROVAL。2026-10-07。
记录功能可以投入 Demo；训练目标、数据范围、预算、拟合及部署均需分别审批。
不把目前的区域参考称为成熟个性买点模型，不以已有规则先赚钱作为一切新研究的前提。

## 一、问题与路线

1. 共性背景：固定 A/B 候选内，哪些盘前已知背景值得观察？不得从仅成功触发股票反推共性价值。
2. 区域/形态：下杀承接、横盘承接、突破启动分开定义；每种形态有相应“不行动”与简单时点参照。
3. 行动价值：同候选、同决策时刻，判断入场相对等待/留现金是否有成本后增量，而不只是60m反弹概率。
4. 个性增量：跨股共享模型后检验个股因果历史摘要的额外价值，不给每股孤立单元格硬凑n。

## 二、阶段与交付

### R0：持续日记与字段盘点（本轮实现，不拟合）

保存完整名单版本、到价及未到价的实际观测、缺失/断流。采样描述和精确标签严格分列。
记录下一轮需要的标签/数据缺口；报价摘要不得直接冒充训练交易标签。
每日可读文档帮助人工查错，不据看到的盈利票增加指标或寻找最优锚点。

### R1：有界历史样本构建（另签）

先冻结候选人口、三类事件、区域集合、比较基线、训练/验证/留出时间与质量口径。
沿用现有已批准指标；MA/BOLL/ATR参考保留，LATR无可核验合同继续PENDING，不增加POC等代理冒名。
逐行保留决策时可用的特征，label_end_ts闭环隔离、公司行为、ST/IPO/限价/成交量/成本按执行合同核验。
不混合CAR与DUAL_PATH人口，不把重复股票日/多区域当独立样本；状态分母、现金0、NULL/残仓分别报告。
先盘点真实分钟覆盖、去重请求与缓存复用，再签数据任务单；既有328对需求不因本计划自动批准。

### R2：首轮共享拟合（R1通过且另行授权）

常数/简单规则基线 → 正则化轻量共享模型。首轮建议L2-LR；新标签/新增信息与旧归档LR不同，不能只是旧四字段重训救结果。
连续/分类预处理、分组/收缩、特征选择只能在训练期拟合；时间外选择阈值须按预注册用途分层。
拟合前落定：主标签、最低样本/日期簇、主经济指标、最低行动覆盖/利用率、左尾、CI和停止条件。
建议数值属于待签提案，不能借用旧30/30/40/80%/10%门作为本轮已冻结标准。
同人口策略差Δ用日期聚类配对不确定性；每策略自身CI不能替代增量检验。
除机会收益，还报告行动子集净收益、拒绝率、可用率、尾部；几乎全拒不能冒充识别值得买的机会。
收益为负或证据不足如实记录，不调共性阈值、事件定义或λ来救已看的结果。

### R3：个性增量（另签）

对同样本/同执行口径比较“共享”vs“共享＋个性历史摘要”，统计借助跨股共享/收缩。
仅已闭环且当时可见的历史入画像；穿透、收回、横盘/突破反应与失败都保留并带不确定性。
先检验新增信息与稳定性，再看经济增量；画像无效则继续只作解释，不把原v0.2失败画像强行进决策。

### R4：新前瞻窗口与接入（另签）

当前历史val/test已反复查看，不能称全新盲测。未来记录一旦参与调优，相应窗口失去独立验证资格。
冻结模型后另留未参与设计的后续窗口；先独立影子运行，通过经济性/尾部/覆盖/兼容性再讨论替换。
不等待日记积累完再做R1，但不能用缺完整分钟的日记代替R1标签。LangGraph/JEV不是前置。
