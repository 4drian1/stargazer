## §3 时间可见性铁律（冻结，按修订4）

- 每套规则**只用决策当时可见信息**；决策时点之后的信息一律不得进入该规则判定。

- 确认不行动 → 留现金（记未行动）；数据不足 → NULL 单列不记零；残仓单列不折现金。

## §4 主指标（冻结，修订1）

**每臂机会收益 = 该事件已闭环净 PnL ÷ 固定资金预算 50,000 元。**

- 确认无行动或确认未成交：**本金留现金，机会收益记 0**——这是"未动用预算"的记账，**不是零交易收益标签**；
- 已成交且完全闭环：计成本后净 PnL（未投入部分保留现金）；
- 数据不足 / 元数据未知 / 残仓未闭环：**NULL，不记 0**；
- **主指标 = H3 两臂机会收益差 Δ = A − B；仅双方可评价事件形成配对**，明示条件子集；
- 成交后单笔净收益另列辅助，不替代主指标；
- **明文：这是固定预算下逐候选机会比较，不是并发账户回测、不报账户回撤**（资金/并发/仓位规则未冻结）。
