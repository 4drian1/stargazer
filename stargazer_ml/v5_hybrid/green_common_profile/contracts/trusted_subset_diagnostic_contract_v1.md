## 1. 研究对象（冻结定义）

**现有可信子集** = 当前通过全部依赖检查的轨道（track）子集。H3/H5 **分别**扣除以下轨道：

1. **跨段隔离轨道**：`CROSS_SEGMENT_LABEL` 轨道（train 轨道 `label_end_ts ≥ 20260309`、val 轨道 `label_end_ts ≥ 20260610`；test 无下段）。逐轨道按 `label_end_ts` 所在交易日判定，规则与 v0.1.1 引擎一致，不得重判或放宽。
2. **公司行为证据（三档口径，修正1）**：
   - **① OK／确认 EMPTY 可用**：证据链 OK，或 EMPTY 为已确认空链（`confirmed_empty=true`）——**EMPTY 不构成排除**；
   - **② UNKNOWN／失败／缺证据 → 隔离**；
   - **③ 窗口内是否存在公司行为 → 另行检查**：`adj_in_window=true` 的轨道**不排除**，单列清单逐条检查，不得以 EMPTY 直接排除，也不以窗口内有行为直接排除。
3. **尺度证据未通过轨道**：价格量纲、成交量纲或执行元数据证据未通过逐笔验证的轨道（证据源：引擎依赖校验 + p2b1 采集 QA 量价尺度核对）。

子集由冻结输入机械导出，**不得**根据子集外表现反向调整纳入规则。

## 2. 完整人口并列报告（冻结）

诊断必须**同时**报告：

- 完整 247 人口状态分布（按段 × A/B 池 × 板块拆分，口径同 `gcp_247_phase1_status_p2b1.json`）；
- 每条排除记录的排除原因（逐轨道：排除类别 + 原始 status/reason）；
- **不得以子集数字替代人口数字**；任何图表/摘要必须能回溯到人口分母。

## 3. 代表性声明与缺失/残仓口径（冻结，修正3）

收益/风险分布仅代表**可复放子集**。显式声明：不是全策略表现；不用于跨期有效性结论；完整率分段偏差使子集构成非随机，任何比较须带构成警示。

**缺失与残仓单列**：

- 未知收益（NULL）轨道**不得排入收益分位**，**不得**假定为亏损或零；
- 缺失（NULL）与残仓（`remaining_shares>0`）各自**单独统计列示**；残仓只报股数，不折现金；
- 分位、均值等一切分布数字仅由已闭环且收益非 NULL 的轨道计算。

## 4. 禁止用途（冻结）

诊断结果禁止用于：调整任何阈值/参数/规则；选择"最佳退出"或退出偏好结论；启动或预热训练（含样本加权/筛选）；按收益挑事件、挑时间段、挑板块构成子集。违反任一，结果自动作废并登记审计。

## 5. 行为标签分离条款（冻结）

行为标签（缺口后 MAE/MFE/箱体等）不是本诊断的前置条件；退出后行为标签缺失不否定已闭环交易（交易标签与行为标签分别判定，解耦）。本诊断只基于交易闭环依赖。

## 6. 测试段完整率偏差条款（冻结）

现有 test 段完整率显著低于 train（v0.1.2 实测 train 90.6% / val 61.8% / test 34.4%），test 子集样本量小且构成偏差未知；test 子集任何结果必须附带样本量与构成偏差警示；**不得声明"新盲测"**（现有测试期已参与研究流程）；跨期有效性结论只能来自规则冻结后的新前瞻时段，另行批准。

## 7. 诊断输出范围（冻结）

仅限：逐笔收益分布（分位/均值/中位数）、风险分布（最差例逐笔列示）、排除原因统计、缺失与残仓单列、持有期双量纲。**不做账户级最大回撤**（资金规模、并发持仓、仓位分配与估值规则未冻结）。不输出盈利排名、策略有效性裁决、买入建议、跨期外推。

## 9. 诊断指标定义（工程口径，修正4）

- **H3/H5 成本后净收益**：`net = C_sell / C_buy − 1`（含滑点+费用，不二次加费）；仅 `fully_exited=True` 且依赖全过的已闭环轨道参与分布；NULL 不入分位（§3）。
- **持有期（禁止直接相减 14 位时间戳，修正4）**：必须用真实交易日历与网格时间解析，分别计算两个量纲——
  - **交易日数** = `cal.index(last_fill 所在交易日) − cal.index(入场成交所在交易日)`（真实交易日历 cal）；
  - **交易分钟数** = 严格晚于入场成交槽、且不晚于最后退出成交槽的**按日期版本网格槽**计数（day < 20260624 用 241 槽网格，≥ 20260624 用 242 槽网格，逐日枚举）；
  - 两量纲分别报均值/中位数，禁止混用。
- **退出方式构成**：TIME / STOP / 顺延多笔（按 sells 的 kind 统计轨道数与占比）。
- **风险分布**：净收益 P5/P25/P50/P75/P95 + 最差例逐笔列示（§10 固定条数）；缺口相关缺失不在分位内（§3）。
- **排除原因统计**：§1 各扣除类别 + 未闭环/NULL 逐类计数。
- 全部指标按 H3/H5 分别报告，再按段拆分；**禁止**跨段合并成单一数字。
