## §3 执行规则同口径、成交路径分算（冻结）

- 两臂**完全沿用**执行合同 v0.1.1 的成本（C_buy×1.0013 / C_sell×0.9982）、参与率 1%、资金上限 50000、板块数量规则、T+1、止损触发与顺延预算（d0+5）、限价规则；执行器缺槽语义（窗内缺 1 槽即拒、完成 bar 后缺槽不否定、入场等待窗缺槽拒）对两臂同口径适用。
- **各臂止损价按各臂自己的模拟入场价计算**（D_stop = clip(1.5·ATR/该臂入场价, 3%, 6%)，ATR 参考窗两臂相同）；两臂止损价不同属规则内自然结果，逐臂记录。
- **成交路径分算**：两臂各自独立模拟成交，不得互借成交；各臂报告自己的成交率与人口状态。
- 未成交保留现金（仅确认未成交才记）；未知元数据 / 未闭环 / 残仓**继续单列不记零**；NULL 不入任何分位。
- 基线臂遇本地分钟缺口 → 与主臂**同一缺槽语义**（NULL 单列，不补不猜不插值）；**本合同不为此批准任何采集**（零网络）。
- **两臂成交率不对称披露条款（预注册）**：两臂决策槽不同 → 缺槽窗口不同 → 两臂 NULL/未成交构成可能不对称（含 E 日分钟覆盖差异、09:35 时段量分布与涨停锁死差异）。处理规则**预先固定**：① 各臂成交率/可用率分别如实报告，不得互相补齐；② 配对收益差仅在**两臂均有效**的轨道上计算，并注明"条件子集结果"；③ 不对称幅度本身作为工程事实列示（各臂 ENTRY_DATA_MISSING / 未成交 / 残仓计数），**不得**通过挑事件或换时点消除不对称。
