## 2. 人口（每日盘前冻结）

- 每日按 P 日及以前已完成日线重建冻结口径 A_SDP/B_LVB 共性资格 + main 箱体（Swing≤2.5 ATR）候选；人口层统一排除 ETF/北交所。

## 3. 两臂与时间可见性（硬条款）

- 对照臂 = 全候选观察 + 冻结 S1/S2；研究臂 = 盘前 contraction≤1.0 才观察 + **同一 S1/S2**；阈值 = 旧研究固定参照，不声称新发现。
- 首次分支只取当时可知 S1/S2（branch 前视教训成文：不用全天 WATCH/未来双触发）。
- 只用已完成 bar；未完成 bar 的量/最低价/未来退出不得提前参与决策。

## 4. 盘中时序状态条款（冻结，强化）

每个决策-撮合时刻按以下状态机执行，任何状态不得越级：

1. **信号**：只能由**已完成 bar** 生成（bar 完成口径：HH:MM bar 于 HH:MM+1 完成）；未完成 bar 不得出信号。
2. **价格参照**：信号后**下一分钟 open** 可作模拟价格参照（观测价，可用于记录与研究撮合的候选价）。
3. **数量确认（硬门槛）**：使用该分钟的**完整成交量**计算参与率/股数，**必须等该分钟完成后确认**——**分钟刚开始不得宣布数量确定**；分钟完成后按冻结执行合同 v0.1.1 的容量/板块数量规则确认股数并落库。
4. 成本/参与率/数量/限价/ST/T+1/止损/H3/H5/d0+5 顺延全部复用冻结执行合同 v0.1.1，引擎不改。

## 5. 数据门（最重要前置）

- 监控机必须提供可靠的已完成分钟 OHLCV；行情轮询快照不能替代分钟 K 线；不得从轮询现价/累计量静默伪造 bar。
- 验收清单（B 阶段逐项）：当日已完成分钟可得性 / 时间戳语义（241/242 日期版本）/ 量额单位与量价尺度 / 板块·ST·上市日·限价依据 / 公司行为来源 / **stockdb 可访问或历史分钟可取 ≠ 实时路径就绪** / 缺槽·源延迟·元数据未知独立留因（两臂依赖各自判定）/ 来源格式变化显式版本化 + 重新验收。
- 无可靠已完成 bar → 只落健康/可用性记录，**不宣称影子已运行**。

## 6. 运行周期、结束与闭环（冻结）

- **T0** = 协议/版本冻结且工程验收后实际启动日，**不回填旧数据冒充前瞻**。
- 周期 = **60 个真实交易日**（已签）；周度描述汇总；窗口结束统一评价。
- **第 60 日停止新增候选；已入场轨道继续观察到退出或合同顺延上限**——结束与标签闭环分离。
- 断源处理：断源超阈值 → 当日及受影响轨道独立留因（NULL 语义），恢复后按"已检查日期覆盖"续扫，不猜缺失价。
- 重启恢复：断点去重（事件/轨道键），不重复计数、不重复落成交。
- 未闭环终态：顺延上限/数据截止到达仍未退出 → 残仓股数单列，**不补零、不折现金**。
- **资金口径**：未定义资金规模/并发/仓位规则前，只报"**固定预算占用**"（Σ实际投入 ÷ 50,000×事件数），**不称账户利用率、不报账户回撤**。
- 出口预注册：闭环等待 / 数据中断 / 样本不足 / 正常满窗；不因某周涨跌改阈值、提前停止或延长。

## 9. 容量与保存预算（收紧后）

- 默认旧+新累计守 50MiB（不因换目录失效）；只引用旧输入不复制缓存；不删历史证据；训练临时额度未批。
- **候选数基线 8/日只是预算估算基线，不是硬上限**：候选超过估算**不得静默截断**（静默截断 = 改变完整人口 = 违规）；资源不足时的合法处置只有两种——**显式停机留因**，或启用**事先冻结的确定性抽样规则**（签署时定并披露覆盖损失）；**禁止按已触发/已盈利事后筛选**。
- **预算额度不在本协议签署时定死**：**B 阶段用工程小样本实测日字节数后再签预算**。
- 存储方案（估算，非承诺）：
  - **方案甲（轻量观察）**：未触发摘要 250B/候选 + 触发候选 E 日分钟（~11KB）+ 依赖登记。**甲的限制必须明示：只存触发事件的 E 日分钟 → 不能完整离线复核未触发判定、过滤效果和退出收益（未触发/被拒候选无分钟留存）**；触发数/顺延路径/日志/DB 开销都可能超出估算。
  - 方案乙（纯摘要 + 已检查日期覆盖登记，分钟现场只读不落地）：最省但断源后不可重放。
  - 方案丙（触发候选全依赖窗分钟）：历史口径估算约 13MB/60 天，**大概率超余量，须 B 实测后另批额度**。
- 留存与可重放边界：以 B 实测为准在预算签署时定稿。
