## §1 样本与标签

- **样本单位 = 已准入事件**（收口件 `r1_label_admission_v0_1_2.json` 的 `admitted` 轨道）。
- **主研究人口 = H3 准入事件 = 124**（train 77 / val 27 / test 20，E 日簇 train 49 / val 23 / test 14）；**H5 = 90 事件仅辅助，不能救 H3**。
- **S2 继续挂起**：BASE_BREAKOUT 27 条 + S2 暴露 1 条维持 PENDING，不进入本人口。
- **主标签 = 已核验现金账本净收益**（`net = C_sell / C_buy − 1`，`C_sell` 汇总全部卖出、`C_buy` 为买入成本，含部分卖出与费用），来自执行标签件 `H3.net`（`dual_path_execution_v0_1_1.py` line 360/501）。**直接使用已核验标签，禁止用单一退出价公式重算收益**。主标签 `label = 1` 当 `net > 0`，否则 `0`。
- **左尾辅助标签** = 同口径 `net ≤ −5%`（仅辅助，不进主标签）。
- 确认无行动 / 未成交 / NULL / 残仓 / 跨段隔离 **不入分类训练**；评价时确认未成交留现金（机会收益 = 0）。
- **标签来源 = 逐事件逐轨道记录**（入场价、净 PnL、实际投入、label_end_ts、有效性原因）；禁用聚合报告反推标签。

## §3 模型阶梯（固定配置）

1. **常数概率基线** = 固定为**训练集正率 37/77（≈0.481）**，仅用于 Brier / 校准类概率评价；**不是放行动作规则**（不据其放行）。
2. **简单规则基线** = 固定 `contraction ≤ 1.0` 放行（不搜索；未验证基线，非最优声明）；作为机会收益对比臂之一。
3. **LR** = 固定 L2、**C = 0.1**（不跑四档；小样本降选择自由度，非最优声明）；**放行规则固定为预测盈利概率 `p ≥ 0.50` 放行、`< 0.50` 拒绝**（首轮研究提案，非已验证盈利门槛；盈利概率高 ≠ 期望收益为正，经济评价仍为主依据）。
- 禁止树 / 深度 / 集成模型本轮进入；禁止大规模调参；禁止按 val 结果回改任何冻结项。

### §3.1 拟合配置（冻结，仅 train 拟合）

- **数值列**（`contraction`、`vol_cv10`）：z-score 标准化，均值/标准差**仅取 train 段**估计，val/test 套用。
- **分类列**（`setup`、`branch`）：one-hot 编码，词典**仅 train 段**拟合；推断时遇未见过类别 → 映射为单一 `unknown` 水平并标记，**绝不崩溃、绝不静默丢弃**。
- **求解器**：`LogisticRegression(C=0.1, penalty="l2", solver="lbfgs", class_weight=None, max_iter=1000, tol=1e-4, random_state=20260928)`。
- **停止条件**：迭代不收敛或预测出现非有限值 → **立即停止，不自动换参数、不重试其他 C/求解器**。

## §4 评价口径与配对方法（必须全含）

- **主比较 = 同事件机会收益差**（配对）：
  - 臂 A = **LR（p≥0.50）**；臂 B = **全放行**（每一已准入事件均放行，交易对照基线）；臂 C = **简单规则（contraction≤1.0）**。
  - 报告 **LR − 全放行** 与 **LR − 简单规则** 的同事件机会收益差（及 简单规则 − 全放行 供参考）。
- **E 日簇重抽（bootstrap）保留配对**：同一 E 日簇内事件在每次重抽中整体出入，保证三臂面对同一组事件，配对差分方差估计正确。种子 20261008 / 10,000 次 / 双侧 95% / 簇内保完整样本 / 事件等权。
- **自身收益 CI 与增量 CI 分别报告**：自身收益 = 该臂实际成交子集的净收益；增量 = 臂间同事件机会收益差，**两者口径不混用**。
- **成本后净收益**：成交子集与全样本框分列（分母口径分别报告不混用）。
- **左尾**（最差例 min(10,n)，仅实际成交轨道）。
- **成交覆盖**：过滤率与可评价率。
- **禁止只看分类准确率**；分类指标至多辅助列。
- **val 主判读；train 拟合；test 非新盲测（已参与设计），仅支持/反证**；不产生 PASS/FAIL 盈利晋级裁决。

## §5 第〇阶段盘点、训练适格与停止边界

- **第〇阶段（随签署生效，零网络）**：train+val+test 三段均报——准入事件数、成交且闭环数（标签分母）、主标签正/负样本数、左尾标签数、标签覆盖率（分母 = 该段全部执行入口，确认未成交另列）、白名单四字段逐字段缺失率、有效 E 日期数；并核验：① 逐行闭环隔离（label_end_ts 后数据不改变标签）；② §2 不变性。**不得据此移动边界、改门槛、选参数。**
- **训练适格条件（门，须满足方可拟合）**：train H3 **正 ≥ 30 且 非正 ≥ 30 且 E 日期 ≥ 40**。本样本满足（正 37 / 非正 40 / E 日期 49）。
- **覆盖限制（单独接受，非门）**：旧 ACTION_FILTER §5 的 80% 覆盖门（分母 = train 全部触发事件 226）**本轮未过**（train 准入 H3 77 / 226 ≈ **34.1%**）。本合同**显式接受此覆盖限制**为已知偏差，不声称继承旧门达标、不得外推全人口。此项为限制声明，**不是需“过”的条件、不具门语义**。
- **停止边界**：完成**三档对照**（常数概率 / 简单规则 / LR）后**即停**；不搜阈值、不调参救结果、不自动线上接入、不上线。
