# EXIT-GREEN-v2 研究设计（2026-09-17 立项，用户定稿）

> 前提：GREEN-WATCH 池把主要矛盾从"入场流灾难"（F1 -19%）变为"接近零轴"（池 -1.3% / BOTTOM -0.1%）。
> EXIT-DYN-v1 的结论是在旧 F1 分布上得出的，**不能自动平移到新池**。
> 本文件是研究设计，不改冻结的 EXIT-DYN-v1；所有结论以池宇宙全量标签为前提（先补标签，再裁决退出）。

## 嫌疑人优先级（用户裁定）

1. **T+5 时间退出**——BOTTOM_SETUP 是"调整到位等启动"，可能需要 T+6~T+10 才进主要盈利段，T+5 强制退出可能恰好砍掉时间优势
2. **第一档移动止盈**（PeakRet≥max(2%,0.8ATR) 启动、回撤≥max(1%,0.45ATR) 退出）——低吸后"反弹→正常回踩→二波启动"是常态，第一档在 +1~3% 就把票甩下车；与"X1 比 X0 每年多亏 2pp"高度一致
3. **反弹失败退出**——"受损0.5ATR→反弹0.3ATR→回落0.2ATR"的判定可能把底部**二次回踩**误判为失败（新特征工程已有 second_low_higher_flag 来区分，机械规则做不到）
4. 硬止损（1.5ATR clip 3-6%）**暂不是第一嫌疑人**，但 BOTTOM vs DIP 可能需要不同 ATR 倍数（BOTTOM 允许更复杂的底部震荡）——只测不猜

## 关键诊断指标（比年化更重要）

- 平均盈利 / 平均亏损 / 盈亏比（BOTTOM 胜率 45.7% 配合这组数字才能定位病灶）
- **MFE capture**：实际退出价 / 持有期最大有利偏移——若大量交易 +1~3% 后被 trailing/T+5 截断而 MFE 远超退出价 → 出口截断右尾
- exit_reason attribution：各退出原因的笔数占比 × 平均净收益（哪个原因在系统性砍盈利）

## 判读预案

- 若 E4/E5（T+10）显著优于 E0/E1 → T+5 是病灶之一，BOTTOM 时间上限进 v2 候选
- 若 E1 > E2 → 第一档小盈利 trailing 确认有害，v2 删第一档只留第二档
- 若 E3 < E1 → 反弹失败确认有害，v2 降级为"二次回踩结构破坏才退"（交给 R0/Timing 判断）
- 若 E0–E5 差异都小 → 退出不是当前瓶颈，回主线练 S0
