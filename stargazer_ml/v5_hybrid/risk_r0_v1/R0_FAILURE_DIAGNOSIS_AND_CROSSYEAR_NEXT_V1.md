## 1. 已确认的问题，不把诊断当因果

输入为首轮冻结的59,923行预测及原80,840行母表。原模型/标签/16字段/主20%过滤规则不变。所有子组继承整日保留名单，不在组内重新挑股票。月度、交易板块和train日期等权市场波动三分位都是探索性描述，不能当新的盲测或搜参依据。

| 指标 | 2025历史留出 | 2026描述期 |
|---|---:|---:|
| 实际五日尾部率 | 13.20% | 24.83% |
| GB平均校准概率 | 12.27% | 16.43% |
| GB整体AUC | 0.7697 | 0.7237 |
| 同日AUC：GB / ATR / LR | 0.8215 / 0.8045 / 0.8255 | 0.7435 / 0.7384 / 0.7467 |

| 保留样本最差5%MAE均值：GB / ATR | −14.24% / −14.37% | −17.31% / −16.34% |

同日AUC按当日正负标签股票对数加权，单一类别日不计AUC但保留在其他统计中。表中AUC差和最差5%MAE差为点估计，未新增置信区间，不据此宣称显著。

结论不是“模型完全失效”，而是概率水平、同日筛选和尾部严重性三件事必须分开：

- 2026实际风险较高，GB低估约8.40个百分点。3月/5月/6月/7月实际尾部率分别32.58%/34.67%/37.16%/35.44%，预测15.96%/16.97%/20.14%/20.34%。风险低估并非只有全年平均值现象，但这不能证明具体根因。
- GB仍有同日排序信息，但比ATR的点估计优势从约0.017缩至0.005，固定过滤比例下尾部次数改善消失。单调概率校准不会解决排序问题，不能把重新校准当完整修复。
- 2026 GB独有保留与ATR独有保留各474行，尾部各199行，次数完全相同；但前者最差5%MAE约−27.17%，后者−19.63%。说明“尾部次数相同”可以掩盖严重程度差异。相邻P日可能来自同一股票同一跌势，不当作独立交易或独立事故。
- 2025 GB独有保留477行中95次尾部，ATR独有保留477行中140次；这定位了原45次差额，不构成新增独立验证。

特征分布有变化，例如2026市场下行波动PSI约0.506、个股20日波动约0.294。PSI采用train股票日分位箱和0.5计数平滑，仅为描述，不设自动门，不证明分布变化导致失效。板块子组各方法保留数可不同，不能直接称同覆盖增量。
