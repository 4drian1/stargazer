## 2. 接口机制验证清单（阶段 1，先于一切案例）

对**一个**代码（000001）深查并记录：
1. **实际生效日字段存在且语义=除权除息日**（不是公告日/预案日/股东大会日）；
2. **实施状态字段**（已实施/预案/取消）及状态过滤口径；
3. **金额/比例单位**（派息：元/股？；送转：每10股？比例小数？）；
4. **历史范围**（最早可查到哪年；2018/2021 案例是否覆盖）；
5. **分页机制**（页大小上限、翻页参数、每页=1 次计数请求）；
6. 响应结构原始样例留证（受控客户端自动归档）。

## 3. 正/负对照判据

- **正对照通过**=接口返回的 (代码, 生效日, 类型) 与本地已知事件在类型上一致、日期与本地公告推断的除权日相容（现金分红生效日≈公告后数日；差异 >5 个交易日标 DATE_DIVERGENCE 留裁决，**不直接算失配也不直接算匹配**）。
- **正对照失败**（已知事件接口查不到）=接口不可用证据，**不得解释为该股票无事件**。
- **负对照**=C5 窗口接口无记录，且与本地语料"窗口内无公告"一致时，可表述为"该接口与本地语料在该窗口均无记录"；**"没查到"与"窗口内无事件"在报告中永远分栏**，不得合并表述。
- 接口不支持的类型（如配股）→ 盲区栏登记，不计入接口通过率。
