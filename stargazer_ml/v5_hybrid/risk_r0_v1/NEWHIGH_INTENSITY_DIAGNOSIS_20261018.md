# 连续滞涨强度与同一时刻风险诊断（#18.102）

状态：**完成零拟合诊断，15分钟有局部正向线索，但未取得跨期稳定证据。** 本轮不是新模型训练，不晋级、不部署，也不否定完整交易体系。

## 实际执行与不变项

原86319共同人口、16个连续比例定义（全/自身板块×5/15分钟×沪/创×不涨/回落）及1200交易分钟/8%标签不变。完整黄金位置/时间、大盘、板块全分布、当前/曾领涨跟踪、个股信息保留；未知不填0。

在看本轮分层结果前固定描述带：`0`、`(0,25%]`、`(25%,50%]`、`(50%,75%]`、`(75%,100%]`。仅在指数已新高且比例已知的行内统计；固定高强度`>50%`与低强度`<=25%`作描述对照，不按标签挑阈值，不把这些描述带改成交易门。

这仍是已经查看过历史结果后的探索性跟进，不称新盲测或事前独立验证。16个定义与全部时间段均报告，无择优、调参或强迫树选特征。

## 1. 全板块与自身板块不能混为一个排序任务

- 全板块比例是同一时刻共享的市场背景，不能靠它在该时刻区分哪只股票更危险。此项个股排序明确记`NOT_IDENTIFIABLE_SHARED_ACROSS_STOCKS`，不是缺数据或特征无效；它仍可能影响整体风险水平。
- 个股所属板块的比例可以因股票不同而不同，适合做同一时刻横向诊断。
- 全板块仅作不同截止时刻的强弱描述；若同日强/弱两状态均出现，先每个截止等权再日期等权。它不能冒充“同一时刻控制了市场背景”的结果。

## 2. 自身板块连续强度：15分钟后段有线索，但早期不稳定

以下指标是**单个比例字段**在同一时刻、标签有正有负的股票之间做风险排序：每个时刻等权汇入日期，再日期等权；同分按0.5计。不是完整模型的AUC，也不是“判断成功率”，不能与整模型全test AUC0.509直接比较成模型提升。

| 自身板块比例定义 | train排序AUC | select | calibration | test |
| --- | ---: | ---: | ---: | ---: |
| 沪指5分不涨 | 0.4987 | 0.5021 | 0.4436 | 0.4235 |
| 沪指5分回落 | 0.5003 | 0.4944 | 0.4439 | 0.4235 |
| 创业板5分不涨 | 0.4838 | 0.5247 | 0.4889 | 0.4571 |
| 创业板5分回落 | 0.4880 | 0.5210 | 0.4892 | 0.4611 |
| 沪指15分不涨 | 0.5078 | 0.4987 | 0.4432 | 0.5901 |
| 沪指15分回落 | 0.5064 | 0.5033 | 0.4450 | 0.5924 |
| 创业板15分不涨 | 0.4836 | 0.5241 | 0.4832 | 0.6138 |
| 创业板15分回落 | 0.4835 | 0.5301 | 0.4856 | 0.6146 |

例如沪指15分不涨：test为0.5901，探索性10观察日块95%区间[0.5354,0.6326]，支持86个混合标签时刻/24日。但334个正负比较对中167对同分，29个混合时刻所有比较都同分；按所有正负对加权而非日期/时刻等权时AUC只有0.5404。权重和支持范围差异不能隐去。

创业板15分不涨：test日期等权AUC0.6138，区间[0.5323,0.6232]，77个混合时刻/22日，按比较对加权AUC0.5456。两者train/select大多约0.5、calibration又低于0.5，不能只选后段的漂亮数字认定稳定有效。

5分钟没有显示一致支持；例如沪指5分不涨test为0.4235，不能事后翻转成反向买入因子来宣称成功。

## 3. 固定强弱组同一时刻对照：存在局部差异，但样本很薄

同一时刻必须同时有`>50%`和`<=25%`两组，才计算现有五日尾部率差；每个时刻等权，再每个日期等权。未同时出现两组的时刻不填充进来。

| 自身板块不涨比例 | test高强度−低强度尾部率差 | 支持时刻/日期 | 探索性95%区间 |
| --- | ---: | --- | --- |
| 沪指5分 | −16.67个百分点 | 10 / 8 | NOT_TESTED，少于10日 |
| 创业板5分 | −3.79个百分点 | 14 / 11 | [−3.79,+5.30]个百分点 |
| 沪指15分 | +23.92个百分点 | 22 / 18 | [+10.19,+44.14]个百分点 |
| 创业板15分 | +23.61个百分点 | 23 / 16 | [+6.25,+29.69]个百分点 |

不能把23.92个百分点当成稳定效果地板。沪指15分不涨的相同对照在train为−0.91、select为−5.60、calibration为+17.48个百分点；测试期只有22个时刻和18日，多条五日标签高度重叠。所有定义均未作多重比较校正，区间只是探索描述，不是晋级Gate。

同一时刻比较也仍存在不同股票的行业/流动性/趋势/其他风险构成差异，并非随机实验或因果效果。

## 4. 连续比例不能简单理解为“越高必然越危险”

例如test沪指15分钟自身板块不涨比例，五个固定档的股票行尾部率为：

| 比例档 | 行数 | 尾部率 |
| --- | ---: | ---: |
| 0 | 391 | 18.67% |
| (0,25%] | 151 | 13.25% |
| (25%,50%] | 58 | 17.24% |
| (50%,75%] | 41 | 19.51% |
| (75%,100%] | 78 | 23.08% |

正比例档出现递增线索，但零档并不最低，不能事后删零档制造单调性；这些档也可能来自不同日期/股票，混合行尾部率不是同cutoff的风险差。

全板块强度也不呈现统一单调关系。例如test沪指15分全板块四个正比例档行尾部率约18.18%、19.43%、16.67%、20.51%；低/高强度同日对照仅14日，差+1.36个百分点。沪指5分同日强弱对照只有4日，不能给正式块区间。

完整16定义/四时间段/月份/固定带、缺失与指数未新高分列均保存在机器报告，不只展示上表。

## 5. 这对后续开发意味着什么

1. 保留板块滞涨作为完整风险框架的一部分。此次不是“板块没用”，也没有证明完整模型已学会这条规则；已有C1树模型新增字段0次分裂使用的事实不变。
2. 15分钟自身板块在后段有值得继续验证的线索，但不足以决定增加权重、强制特征、改阈值、重训或接入交易决策。5分钟也不因本次反向结果直接删除或反转。
3. 当前主任务衡量未来1200交易分钟/8%风险，不是盘中短时下杀。**尚不能证明时间尺度不匹配就是原因，更不能声称短期一定有效。** 下一项合理工作是与用户明确并冻结独立的盘中短期辅助观察目标，再在既有本地数据上验收，而不是继续在旧test换分层寻找好结果。
4. 如推进短期辅助研究，先确定参考价、未来交易分钟窗口、观测最大下探/阈值、跨午休与隔夜、缺槽与公司行为规则；不替换原五日主目标，FIT仍另行裁决。该辅助目标本轮未定义/生成/训练。
5. 原历史快照成员偏差、受限普通公司行为证据、未知历史原始到达时间、重叠标签和旧test研发复用均继续披露。黄金/大盘/板块/领涨/个股整套方案不删层，不把单字段诊断替代全体系。
