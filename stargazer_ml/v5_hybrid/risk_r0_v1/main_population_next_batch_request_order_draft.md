## 4. 窗口与比对规则（用户 2026-10-13 修订并冻结）

**±90 天只能作为检索范围，不能作为事件匹配容差**（原口径会互相遮蔽：
相隔数月的两件事件可能被判"有对应记录"，漏记也可能被掩盖）。冻结口径：

1. **检索范围**：每码窗口 = P±120 自然日 ∪ 该码全部缓存事件日±90 自然日（P=最早 P，
   来自冻结人口）。窗口只决定"看哪里"，不决定"是否匹配"。
2. **日期匹配只认实际生效日精确一致**（外部除权日 == 缓存事件日，逐日相等）。
   **非零日期差一律单列 `date_diff_pending` 待裁决**，不得并入命中或差集。
3. **日期命中不代表类型、实施状态或因子已匹配**：命中项必须再分
   `TYPE_PARAMS_CONSISTENT_NO_CASH` / `CASH_ONLY_FACTOR_NOT_COMPARABLE` /
   `TYPE_ALLOTMENT_NOT_COMPARABLE`（配股无进度列，按候选保留）/
   `MIXED_PARAM_PENDING`（送转+派混合，13 条类事件**后置另案**，本批不核销）。
4. **最早 P 附近的诊断窗口不代表该股票全部候选五日窗口已核销**——全历史诊断单列，
   窗口结论不得外推。
5. 双向差集（在精确匹配口径下）：
   - `outside_cache`：窗口内外部实施事件，**既无精确同日缓存事件，±90 检索范围内也
     无任何缓存事件**（真缓存漏记候选）；
   - `date_diff_pending`：±90 检索范围内有缓存事件但日期不精确相等（疑似同一事件
     日期口径差异，未裁决）；
   - `not_returned`：缓存事件日无精确同日外部记录（候选：表外事件/停牌/漏抓，未裁决）。
6. EMPTY 层结果一律表述为"**未检出记录**"，不认证"无事件"；MISSING 层表述为整码缓存缺失。

## 5. 来源盲区（实证登记，执行与解释都必须携带）

1. **新浪页表外事件不可见**：特别分红、要约、缩股、破产重整除权（000564 实证）、
   分立等不进入分红/配股两表 → 外部"无记录"对这类事件永远成立，属**结构盲区**不是"无事件"。
2. **停牌类事件本线完全不覆盖**（批次 a 实证：searchkey 路径 2018 零记录），

   不得默认已实施。
4. 早期年份记录质量：占位公告日（1900-01-01）、除权早于公告的错位行
   （批次② 000002 1992 例，未裁决）——早年对拍结果须降权解释。
5. "不分配"行不是事件；进度缺失行按排除登记。
