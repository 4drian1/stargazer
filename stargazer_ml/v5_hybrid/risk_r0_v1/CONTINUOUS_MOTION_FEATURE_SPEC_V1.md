# 连续板块／领涨动能研究字段 V1（#18.107）

## 本次冻结的含义

补足“还在涨，但越来越慢”，不是把整套风险架构拆成独立策略。黄金位置／时间、大盘、板块全分布、当前及曾领涨股、个股仍共同使用；本次不重训、不改旧232字段模型或标签，不强迫树分裂。

现有context_sector_minus_sse_return_raw等为当日累计相对强弱；own5/15_common_change为相邻时刻共同成员的当日收益变化，并非本次同尺度复利区间收益。旧观测已有interval_return及drawdown_from_close_day_high，直接复用，不作为新价格证据或全新信息。仅板块/领涨股的连续减速及相对减速表达需要补齐。

## 六个连续值（单位为收益小数）

1. motion_interval_return：既有已完成5／15分区间收益r(t)，同源复用；不把旧“当日涨幅变化”混称复利区间收益。
2. motion_deceleration = r(t−1)−r(t)。正数表示减速，负数表示加速；r(t)>0时也可减速。不需要“必须先转负”或新硬阈值。观察两次相邻区间收益至少要相应历史完成bar，不额外等待未来右侧确认。
3. motion_giveback = −既有当日已完成收盘高点回撤。正数表示从已观察高点回吐，峰值按收盘而非盘中high；不偷换成全天最终高点。
4. motion_relative_return = 实体r(t)−指数r(t)。负数是同窗跑输，即使实体仍在上涨；不使用近零指数涨幅作除数。跑输不自动等于危险，波动性/正常轮动差异保留给联合研究。
5. motion_relative_deceleration = 实体减速−指数减速。正数表示比指数减速更多。
6. motion_relative_giveback = 实体回吐−指数回吐。正数表示回吐更多。

板块/沪指/创业板指同一频率同一截止，精确连接、未知不asof填充。相邻两段须同一日同一上午/下午时段且间隔恰好5或15分钟；午休只断开减速比较，已知当日高点不清零。日切重置。字段不以指数必须新高为前提，同时保留原指数新高上下文；避免刚离开新高时信号被硬置0。

## 成员、龙头与汇总

- 板块的局部区间比较须既有正向完整成员/稳定参考口径支持；高点回吐另须当日路径前缀完整。缺槽、成员变化未证可比、未知均保留NULL，不能补0制造衰减。
- 龙头沿用当前当日涨幅和此前捕获保留的名单。先按(board_code,code)计算同一股的减速，再选择当前/保留组，不把“上一根领涨A、下一根领涨B”的平均变化冒充某股减速；不按成交量或事后收益挑龙头。
- 提供全板块／当日上涨板块及当前／保留领涨组的已知值均值、10/50/90分位、已知数/未知数/覆盖率。空组NULL；组统计不替代个股所属板块单列。真实工程报告跨时刻合并分布仅用于检查计算，不是日期等权风险有效性证据。
- 先计算实体路径，再汇总；不能对5分钟只保留15分钟采样后计算“相邻5分钟减速”。
