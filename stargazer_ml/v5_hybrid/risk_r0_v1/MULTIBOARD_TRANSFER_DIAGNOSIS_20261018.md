# 跨期失配与5/15分钟预警时效诊断

状态：**只读诊断与读回验收完成，未重训、未重新校准、未改标签或完整架构。** 路线#18.93。以下是可复核的线索，不是唯一因果根因或风险晋级结论。

## 结论与优先级

本轮并非“只是模型参数不够好”。已确认：① 成员行情覆盖发生明显跨期变化；② 关键的个股所属板块新高/滞涨字段几乎不可评价；③ 同时刻相对风险与跨日期绝对风险的排序表现不同，全局负斜率校准不能掩盖这种差异；④ 当前标签主要标记数日后严重不利波动，不是即时下杀。

优先修观察覆盖和关键预警的可知表达，再研究跨期校准。暂不加树、不删板块/龙头层、不改8%阈值，也不把本次诊断挑出的字段直接用于下一轮选择。

## 1. 不是简单“换了一批股票”

固定四段共有的19只股票，仅作事后诊断子集，不改变原训练人口：

| M1 LR原始排序 | train | select | calibration | test |
| --- | ---: | ---: | ---: | ---: |
| 原共同人口AUC | 0.7559 | 0.5564 | 0.4189 | 0.5021 |
| 固定19股交集AUC | 0.7509 | 0.5610 | 0.3777 | 0.5072 |

换成相同代码后，校准段反向排序与测试近随机现象仍存在。因此，股票构成变化不能独自解释全部失配；这不意味着其他组成/市场变化已被排除。

校准段M1 LR总体AUC为0.4189，同截止正负样本成对AUC为0.6581；固定19股后分别0.3777和0.6529。说明横截面相对排序和跨日期混合排序并不等价。负斜率校准会把同一时刻的排序也整体翻转，不能当作恢复了稳定风险能力。

测试段M1 LR同截止成对AUC仅0.4395，M1 LightGBM仅0.5285，仍不支持稳定泛化。这里的成对AUC只用同截止同时存在正负标签的截面，按正负样本对数加权，不要求至少5股；它不是原等比例过滤人口的指标，也不是“成功率”。所有这些控制均未产生新预测。

## 2. 板块覆盖发生了明显漂移

相同固定快照、相同特征定义和原共同人口下：

| 分段 | 全板块15分钟平均成员覆盖 | 个股所属板块15分钟平均成员覆盖 |
| --- | ---: | ---: |
| train | 65.84% | 67.37% |
| select | 65.93% | 67.55% |
| calibration | 59.47% | 60.83% |
| test | 45.28% | 46.90% |

全板块15分钟成员覆盖字段的训练范围为61.46%–66.01%，test的取值100%落在训练范围外。个股所属板块覆盖字段有70.31%的test记录落在训练范围外。这是具体输入范围变化，不等于市场风险本身变了，也不等于沪指/创业板指缺失；缓存截止、缺槽、参考价和成员准入各自造成多少影响，尚须有界归因。

M1 LR固定线性项的精确分解：test相对train的平均logit变化−2.1595，其中数值项合计−2.4433、缺失指示项反而+0.2837。新增全板块数值项合计−1.9072，新增所属板块数值项−0.2556。说明“只是把NULL填好即可”的说法不成立：已提供的覆盖/分布数值也在改变模型输出。该分解是固定模型的算术解释，不证明这些输入具有因果作用或应该删除；平均logit也不等于平均概率的logit。

例如mb15_member_coverage单项的test平均logit贡献相对train约−0.9282。所有字段的漂移与贡献完整保留，而非只留下事后最好看的字段。

## 3. 关键新高/滞涨信号并未真正充分可用

以own15_sse_positive_not_new_high_rate为例（“个股所属的当时上涨板块组，指数新高而板块未创新高”）：

| 分段 | 全记录 | 可评价 | 未知 |
| --- | ---: | ---: | ---: |
| train | 60,712 | 1,179 | 59,533 |
| select | 18,071 | 367 | 17,704 |
| calibration | 4,548 | 113 | 4,435 |
| test | 2,988 | 21 | 2,967 |

test未知99.30%，但不能统称“缺行情”：786条是没有当前上涨的所属板块，分母为空；2,181条是上涨组非空、却无可评价的新高比较；未解释的其他原因0条。空组不是风险为0，也不应靠填补伪造；非空组无法认证新高比较才是需要针对性排查的部分。5分钟同类字段未知也是2,967条，但两类原因分别787/2,180，不能混用计数。

相比之下，own15_sse_positive_nonpositive_rate（同段指数上涨而板块不涨）在test有2,202条可评价。原构造对“板块日内新高”要求成员身份与必要前缀完整；不能从共同成员同段变化反推整个板块的新高。两种信号不同，不能把后者已有值当作前者已经实现。

全局“至少有某个上涨板块的领涨股转弱”出现十分频繁：train的全局5分钟current_change_negative_rate在2,469个唯一截止中2,466次大于0，test为775个截止中774次。**不能将“全市场任一龙头转弱”机械改成一票否决。** 这不表示连续比例没有信息，原模型输入仍是比例数值；风险判断必须保留黄金位置、大盘、板块、领涨股和个股的联合语境。

共享全局信号按唯一截止统计；所属板块信号按候选×截止统计。条件尾部率另按候选记录描述，均不当成独立事件或因果检验。零、激活、未知三种状态完整保留。

## 4. 5/15分钟观察与五日严重风险不是同一时间尺度

只对已有阳性记录，读取其原冻结分钟源、日历、因子和隔离清单；严格从决策之后一根分钟开始测量首次8%触及。11,365条已有阳性记录的原MAE与label_end全部复现，未产生其他期限/阈值的监督标签。涉及27只有阳性的股票；模型共同人口仍为28只，不把无阳性股票删除。

| 分段 | 已有阳性记录 | 前60交易分钟已触及 | 前240交易分钟已触及 | 首触中位交易分钟 |
| --- | ---: | ---: | ---: | ---: |
| train | 7,693 | 3.09% | 16.69% | 616 |
| select | 2,386 | 2.18% | 10.73% | 669 |
| calibration | 764 | 2.75% | 13.22% | 543.5 |
| test | 522 | 1.53% | 7.85% | 791.5 |

“前240交易分钟”是从决策以后数240个交易槽，可能跨午休、隔夜，不等于当天或自然24小时。记录的标签窗口相互重叠，522条阳性也不是522次独立暴跌。

现有目标确实主要描述较迟发生的严重风险。它不能直接回答“未来15/60分钟是否动能衰减/下杀”，但晚发生本身也不能证明5/15分钟信号没有长期风险预测力，不能据此自动更换标签或宣告新架构无效。
