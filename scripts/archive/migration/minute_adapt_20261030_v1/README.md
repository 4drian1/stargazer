## 2. 原生 5 分钟读取

- **格式**：32 字节定长记录 `<HHfffffiI`（日期包 + 分钟 + OHLC **float32** + amount float32 + volume int32 + 保留）。
- **编码已实证确认**：`sh600000` 末根收盘 = 10.02，与已知日线收盘一致；若按 int×100 读会得到 1002（已排除）。

- **读前后不变**：每个文件读后重读比对 sha256，`read_immutable=true`；若并发写入会抛 `SOURCE_MUTATED_DURING_READ`。
- **校验**：日期合法、48 槽、网格精确（09:35–11:30 / 13:05–15:00）、OHLC 关系、价格与成交额有限为正、量额非负、时间戳严格单调无重复。

**与已验收镜像对照（指数）**：与 `index_minutes_v1` 已验收镜像比对 21,975 根共同 bar —— **453 天逐位相等（最大差 0.0）**；20261026 起 5 天出现最大 0.0051 差异，来源是镜像该段为公开源（不同供应商）替换，非解析错误。这是本轮"独立适配 + 对照"的最强证据。

# 日线报告三项限定（并行处理，最终切换时一并验收）

以下为日线侧必须保留的限定，**本轮未改动日线生产入口**：

1. **股本快照不能铺成历史股本序列。** 当前把同一份股本写到所有历史日期，历史市值、换手率因此**不是已验证数据**，应标为"快照估算"或保留未知。不得因解出股本事件就宣称全历史已覆盖（历史股本事件需另做时间序列验证）。
