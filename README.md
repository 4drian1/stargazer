# Stargazer

**本地运行的 A 股观察与交易计划辅助程序（不自动下单）**。
盘后本地选股 → 人工确认计划 → 盘中按冻结规则监控并推送提醒 → 人工登记成交 → 盘后复盘归库。

- 程序只做观察、证据与提醒；**任何买入/卖出都由人完成并在页面登记**，程序不连接券商、不下单。
- 选股模型（Tarot）、风险证据（Pyxis）、信息层（Corvus I33+D2）各自独立，缺失时如实显示"未知/缺失"，不补造。
- 桌面端为 **pywebview + Flask** 的本地单实例应用（新 React UI，页脚显示构建版本号便于核对）。

## 主要功能

| 模块 | 说明 |
|---|---|
| 交易计划 | 盘后选股（本地日线，约 10 分钟）→ 草案折叠核对 → 修改可保存为新版本草案 → 确认/拒绝 → 生效计划（含关注区、三选二入场说明、有效期） |
| 监控板块强势股 | 按强势回调规则对监控板块成员筛选，与正式选股结果分开；逐板块状态（就绪/准备中/失败/等待日线/历史结果）、展开真实股票与黄金观察区、自动准备（中断可恢复，同版复用不重算） |
| 同花顺板块身份 | 行业/概念板块按名称/指数代码/网页编号/旧目录身份精确解析到同一身份；成分版本化保存，历史成员注明快照日期 |
| Stargazer 助手 | 对话式操作：制定/修改计划、人工观察、复盘交流；后台会话与审计保留，页面以对话为主 |
| 复盘 | 持仓/计划/实际成交三类对照；可进入助手补充讨论后明确写回（幂等，重启可读）；区分实际成交与假设回放 |
| 持仓 / 观察名单 | 登记真实成交（幂等防重复提交），数量/加权成本/可卖（T+1）/盈亏自动计算；观察名单增删改与重启读回 |
| Corvus 信息 | 统一信息链 I33＋D2：近期/历史/日期不可得分组展示；主卡片为概括/摘录摘要/可能影响/披露时间/来源/原文链接，技术字段折叠 |
| 全球市场 | 美股指数、COMEX 金银、WTI/布伦特原油、日经 225、欧洲斯托克 50、中美 10Y 国债收益率（免费源快照，缺项如实标注） |
| 每日塔罗 | 工作日 09:00 推送当日塔罗+星象（事实核可选 LLM 人格润色，失败静默回退本地文案） |
| 推送 | Server酱 / PushPlus / 钉钉（markdown 段落+加签）三通道；推送关闭时不消耗去重资格 |

## 隐私与密钥政策（红线）

- 真实密钥**永不入库**：`config.yaml`、各 `tokens.yaml`、`.secrets/` 均被 gitignore；仓库只提供 `*.example.yaml` 占位模板。
- 本机私有路径同样不入库：TDX vipdoc 路径由环境变量 `STARGAZER_TDX_ROOT` 或本机 `data/tdx_root.txt`（已 gitignore）提供。
- 交易计划、持仓、成交、行情缓存、模型权重、发布产物一律不入库。
- 即使仓库转 Public，任何一次提交中的密钥都会永久可见，所以密钥只走本地文件。
